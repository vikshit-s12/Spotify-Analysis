# Spotify-Analysis
🎶 Analyzing music trends and user preferences using Power BI & DAX

Description:

📊 This project focuses on analyzing Spotify music data to uncover insights into song popularity, artist performance, and listening trends.
🎯 The primary goal is to leverage Power BI and DAX for data modeling and visualization, while using Python for initial data validation due to the large dataset size.

Tech Stack:

📊 Visualization - Power BI
🧠 Data Modeling	- DAX (Measures, Calculations)
🐍 Data Validation -	Python (Null value checks)
📁 Data Source -	CSV / Excel

Data Source:

🌐 Public dataset from Kaggle / Spotify Open Data
📌 Contains:

🎵 Track Name
🎤 Artist
📅 Release Year
🔥 Popularity Score
🎼 Audio Features
